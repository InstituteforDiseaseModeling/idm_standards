However, links in Jupyter notebooks are not parsed the same way they are in Markdown. Instead of link text like you would do in a .md file, you need to use link text. So go up an extra folder level and leave off the .md file extension. Otherwise, users will see a 404 when clicking links in notebooks.

    We strongly recommend providing users the ability to interactively run notebooks in their browser by providing a link to a compute server such as Binder, GitHub Codespaces, or Voila. You can create individual buttons to Binder in each notebook using the format:

    Notes on math¶

    Note that the mathjax LaTeX parser used with MkDocs cannot render inline (within a sentence) LaTeX correctly in Jupyter notebooks. LaTeX blocks (on a separate line) are rendered correctly, as are inline LaTeX and LaTeX blocks within Markdown files. If you need to include simple math within sentences, use italics with the English alphabet and add Greek symbols directly. For example, S+I+R=N and β or γ. If you need to add subscripts or superscripts, you can use HTML tags, for example R0.

    %matplotlib inline
import starsim as ss

# Define the parameters
pars = dict(
    n_agents = 10_000,    # Number of agents to simulate
    networks = dict(      # *Networks* add detail on how the agents interact with each other
        type = 'random',  # Here, we use a 'random' network
        n_contacts = 10   # Each person has an average of 10 contacts with other people
    ),
    diseases = dict(      # *Diseases* add detail on what diseases to model
        type = 'sir',     # Here, we're creating an SIR disease
        init_prev = 0.01, # Proportion of the population initially infected
        beta = 0.05,      # Probability of transmission between contacts
    )
)

# Make the sim, run and plot
sim = ss.Sim(pars)
sim.run()
sim.plot()
sim.diseases.sir.plot()
