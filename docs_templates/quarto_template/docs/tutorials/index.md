# Tutorials

Tutorials can be formatted as Jupyter notebooks (.ipynb) or Quarto Markdown (.qmd). Quarto Markdown has several advantages, including readability, ease of authoring and support for a mix of R and Python in the same kernel. However, user interaction is limited to plotting and widgets, not running simulations. If you want users to be able to interactively run simulations, use Jupyter notebooks with a link to Binder.
